# AngoDate

App de namoro em Angola para estrangeiros. Pagamentos (Kz) geram beneficios: Premium (ver quem gostou, 100 likes/dia, 1 impulso, tradutor) e VIP (likes ilimitados, mensagens sem match, selo verificado, 5 impulsos); impulso avulso 24h.

Correr: `npm start` (porta 3000). Testes: `npm test`.
Nota: o gateway de pagamento e simulado; integrar Multicaixa Express/EMIS em producao.
